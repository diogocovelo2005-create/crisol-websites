# Efeitos já usados

Para os sites não ficarem todos iguais. O `interatividade-alojamento` lê
esta lista antes de escolher o efeito marcante de uma casa, **não repete o
efeito marcante de outra**, e no fim acrescenta uma linha com o desta casa.
Os efeitos de apoio podem repetir-se, mas evita usar o mesmo conjunto.
