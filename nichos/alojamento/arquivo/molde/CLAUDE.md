@AGENTS.md

Este molde é base técnica e exemplo de execução. Ao criar uma proposta para uma
casa, segue adaptar-molde: primeiro fotografias, argumento e composição própria.
O catálogo contém apenas exemplos opcionais. Não é um menu nem define secções,
três momentos ou horas obrigatórias. Podes alterar toda a apresentação e os
dados, criar componentes e dispensar protótipos. Mantém rigor factual,
acessibilidade e verificação. A entrega é uma base apresentável, sem exigir
acabamento final; trocar apenas nomes, cores e fotos não basta para diferenciá-la.
