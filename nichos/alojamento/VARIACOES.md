# Variações dos sites de alojamento

Uma linha por site. Não se apaga nem se reescreve uma linha antiga. Este
ficheiro ajuda a detetar repetições automáticas; não proíbe reutilizar uma boa
variante quando ela é a escolha mais coerente.
