# Padrão das inspirações e três variações

Feito pelo `prototipos-alojamento`, antes de construir. Grava
`prototipos/PADRAO.md` e `prototipos/variacoes.json`.

## O padrão

As inspirações são as que o Diogo deu, em `prototipos/inspiracao/`. Não é
para replicar nenhuma, nem para fazer cada protótipo a partir de uma: é para
perceber **o que têm em comum** e ir de encontro a isso. As secções das
inspirações não interessam: o conteúdo e a ordem vêm do `BRIEF.md`.

Vê as capturas **juntas, uma só vez**, e escreve o que se repete entre elas,
até 30 linhas: combinações de cor (relações, não hex), tipografia, ritmo,
maneira de apresentar as fotos e o texto, e o que está ausente em todas.
Descreve o que está nas imagens. Não acrescentes gosto teu.

## As três variações

Os três protótipos seguem o padrão e são **visivelmente diferentes**. A
diferença está em:

1. **Maneira de apresentar**: como se conta o mesmo conteúdo, pela mesma
   ordem (capítulos, planos largos, pormenores, colunas editoriais…).
2. **Ritmo**: onde a página corre e onde pára, a densidade, o espaço.
3. **Composição**: como se arrumam as secções, as fotos, as citações, os
   quartos, os contactos.
4. **Tipografia**: o par de fontes e a escala.

A **paleta** varia pouco: sai sempre das cores das fotos da casa
(`fotos.md`), e entre os três protótipos muda só um pouco (a temperatura, o
tom escuro, o acento). Não é o que os distingue.

Diferentes entre si, mas os três dentro do padrão: entre diferente e fiel
às inspirações, ganha fiel.

`variacoes.json` (lido pela página de escolha):

```json
[
  { "letra": "a", "nome": "nome curto em português", "ideia": "uma frase para o cartão" }
]
```
